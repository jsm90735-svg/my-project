반도체 클린룸 VR

반도체 클린룸 공정을 VR로 체험하는 교육 콘텐츠에서 기능 구현을 맡았습니다. VR 실기기 테스트로 문제를 직접 찾고, 원인을 좁혀 해결 방향을 정했습니다.

내 역할 — 4인 팀의 Unreal Engine 기능 구현

02 핵심 1 · 포토공정 장비 인터랙션 (직접 구현)

스핀코터·마스크얼라이너·디벨로퍼·베이크 장비를 실제 공정 순서대로 조작하도록 블루프린트로 구현했습니다. ChatGPT에게 방법을 물어가며 노드를 직접 연결했습니다.

  • 공정 순서: 웨이퍼 장착 → 초록(VACUUM) 버튼 → 빨강(START) 버튼 → 회전
  • 상태 관리: 장비 상태를 7단계(대기 → 웨이퍼 대기 → 장착 → 진공 → 회전 준비 → 작동 → 완료)로 나눠, 지금 눌러야 할 버튼만 반응하게 했습니다.
  • 감지 영역: 웨이퍼 앞과 버튼 앞에 감지 박스를 두고, 서 있는 위치에 따라 웨이퍼 장착과 버튼 조작을 나눕니다.
  • VR 레이저: 레이저가 버튼에 맞았을 때만 VACUUM·START가 눌립니다. 이 판정은 이후 AI(Claude)와 함께 추가했습니다.

나레이션 단계별 조작 잠금

설명을 다 듣기 전에는 다음 버튼을 누를 수 없게 만들었습니다. 교육용 콘텐츠라서, 학생이 버튼만 연달아 눌러 공정을 건너뛰는 것을 막기 위해서입니다.

  1. 1번 나레이션이 끝나야 웨이퍼를 올릴 수 있습니다.
  2. 2번이 끝나야 VACUUM 버튼이 풀립니다.
  3. 3번이 끝나면 4번을 재생하고, 그동안 조작을 잠급니다.
  4. 4번이 끝나야 START 버튼이 풀립니다.
  5. 5번이 끝나면 공정이 끝나고 처음 상태로 돌아갑니다.
03 핵심 2 · VR 테스트로 찾은 문제와 해결

PC에서는 멀쩡하지만 VR 헤드셋에서만 생기는 문제를 직접 플레이하며 찾아냈습니다. 원인을 좁히고 해결 방향을 정한 뒤, 수정은 AI(Claude)와 함께 적용했습니다.

문제 (내가 발견)원인조치 / 확인 상태
에어샤워에 반대 방향으로 들어가도 문이 열림 (VR에서만)문에 바짝 붙은 감지 박스가 VR 손(컨트롤러)까지 감지함감지 박스를 40cm 바깥으로, 몸(Pawn)만 감지
문에 부딪히면 나레이션이 다시 나옴감지 범위를 벗어났다 들어오며 다시 시작감지 범위 조정
패널실 버튼이 나레이션 시작하자마자 깜박임소리가 중간에 끊겨도 '끝'으로 처리됨최소 55초 들어야 버튼이 열림
스핀코터 START 버튼이 초록 버튼 앞에서만 눌림웨이퍼 감지 박스가 START 바로 옆에 붙어 있음위치가 아닌 장비 상태로 판정 + 버튼 감지 범위 확장
에어샤워에서 에러 10개 발생바람을 보여주려고 넣은 비닐 효과가 원인비닐 효과를 오류 원인으로 식별

에어샤워 문 감지

주황색 상자가 문 감지 범위입니다. 문 안쪽이 아니라 들어오는 쪽에만 두어, 안에서 부딪혀도 문이 열리지 않게 했습니다.

패널실 나레이션 → 버튼 잠금 해제

나레이션이 끝났다는 신호가 와도, 실제로 55초 이상 재생됐을 때만 버튼이 깜박이며 문이 열립니다.

스핀코터·디벨로퍼 버튼 감지

  • 두 감지 박스가 걸쳐 있어서, START 앞에 서면 '웨이퍼 앞'으로 판정됐습니다.
  • 박스 위치만으로는 두 곳을 나눌 수 없어서, "지금 버튼을 눌러야 하는 상태면 버튼으로 판정"하게 바꿨습니다.
  • 디벨로퍼는 같은 기종이지만 작동 방식이 다를 수 있다고 보고, 먼저 비교하게 한 뒤 같은 수정을 적용했습니다.
04 핵심 3 · 장비 설명 UI

장비 앞에 가면 캐릭터가 설명 글을 손으로 가리키는 설명창이 나타나게 했습니다. "손이 가리키는 쪽에 글이 있어야 한다"는 배치를 제가 정했고, 실마다 다른 포즈의 캐릭터 이미지 3장을 준비했습니다.

  • 16개 장비에 실별 캐릭터 이미지를 배정했습니다 (3실·4실·5실).
  • 설명창 하나를 만들고, 장비마다 이미지·장비명·설명만 바꿔 재사용합니다.
  • 이미지 리소스 크기를 줄이기 위해 최대 해상도를 512px로 제한했습니다.
05 현장 조사 기반 콘텐츠

팀이 반도체학과를 직접 방문해 실제 클린룸과 장비를 기록하고, 그 자료로 공간과 공정을 만들었습니다.

노란 조명은 실제 포토공정 구역의 황색광을 재현한 것입니다. 감광액이 빛에 반응하지 않도록 쓰는 조명입니다.

자료출처
장비·공간반도체학과 방문 (360 카메라, 영상·사진 촬영)
공정 설명반도체학과 교수님 설명, 학과 학생 2명 조언, 반도체학과 출신 기획자
방진복실제 사진
캐릭터폴리텍대학 캐릭터
나레이션무료 AI 음성

VR이 처음인 학생도 따라올 수 있도록, 첫 방에서 이동과 회전 조작을 먼저 안내합니다.

방진복실에서는 방진복을 입은 캐릭터를 보며, 레이저로 버튼을 눌러 다음 단계로 넘어갑니다.

06 작업 방식과 AI 활용 범위

구현은 AI 도구(ChatGPT, Claude)를 적극적으로 썼고, 무엇을 고칠지와 어떻게 고칠지는 제가 정했습니다.

제가 한 것AI가 도운 것
VR 헤드셋으로 직접 플레이하며 문제 발견블루프린트 노드 연결과 수정
해결 방향 결정, 고치기 전 상황 분석을 먼저 요청원인 분석 자료 정리
수정 후 재테스트, 효과 없는 변경은 되돌리기백업과 변경 내역 비교

제가 직접 찾거나 정한 것

  • PC에서는 없고 VR 패키징 빌드에서만 에어샤워 문이 열리는 것을 발견
  • 감지기를 문 바깥으로 빼자고 제안, 양방향 진입 문제까지 고려
  • 문에 부딪히면 나레이션이 다시 나오는 것을 발견
  • 패널실 버튼이 나레이션 시작과 동시에 깜박이는 것을 발견
  • 스핀코터 START 버튼의 감지 범위가 좁다고 판단하고, 포토공정 장비 4종을 모두 점검하게 함
  • 디벨로퍼는 같은 기종이어도 작동 방식이 다를 수 있어 비교부터 하게 함
  • 에어샤워 에러 10개가 바람을 보여주는 비닐 효과 때문임을 파악
  • Quest 해상도를 1.1배로 올려 시험하고, 효과가 없어 되돌리기로 결정
  • Quest용 조명 중 9개를 직접 끄고 위치를 지정
  • 설명 UI의 "손이 글을 가리키는" 배치를 기획하고 이미지 준비

지킨 작업 원칙

  1. 고치기 전에 백업한다.
  2. 필요한 곳만 최소한으로 고친다.
  3. 바꾼 노드에는 [CleanPass] 주석을 단다.
  4. 고친 뒤 VR로 다시 테스트한다.
